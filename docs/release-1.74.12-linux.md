# 红果短剧 Linux v1.74.12

- 新增时间轴弹幕。开启「弹」后按播放位置显示，可以切换到本集公开评论。弹幕接口异常或官网跳转到其他分集时会给出对应提示。
- 选集显示下一可播集的准备状态，支持跳到指定集数、查看已看标记，以及从下一季自己的进度继续观看。
- 新增应用内全屏，可按需打开选集和播放信息，显示实际片源、分辨率与解码方式。
- 预缓存支持关闭、仅下一集或后两集。切集可接管已有准备任务。Linux 默认优先播放原片，需要兼容转换时尝试 Intel VAAPI。
- App 取源空响应时先试备用入口，当前集和下一可播集可按限额共享会话恢复。
- 使用新应用图标，下载、反馈及后续 Linux 更新统一使用 `mantougg/hongguo-drama-linux`。

首次从其他发行渠道迁移时，下载 `hongguo-drama-1.74.12-linux-x64.tar.gz` 和 `SHA256SUMS.txt` 并校验。解压后运行 **`升级现有安装.sh`**，使用同一个应用菜单入口和本地观看资料。首次安装可运行 **`install.sh`**。

桌面试播和播放回归见 [连续追剧体验验证](linux-watching-experience-design.md#验证记录)。
