# 红果短剧 Linux v2.0.0

- 支持红果 App 仅提供 ByteVC2 的分集。在线播放、预取和下载会把这类片源转换为原分辨率的 H.264，保留 AAC 音轨。已有符合画质要求的 H.264 或 HEVC 片源时，优先使用原片。
- 播放器和下载页显示等待转码及实际转换进度。切到正在预取的分集时，可继续使用在途任务。已完成的转换可复用，固定画质继续按实际尺寸校验。
- Linux x64 包内置 ByteVC2 解码组件，可直接在现有安装中检测更新。默认使用 CPU 转换。Intel VAAPI 编码可通过 `HONGGUO_BYTEVC2_VAAPI=1` 手动开启。两集实测转码更快，但输出文件大了约 76%–86%，因此暂作为实验选项。

发行页提供 Linux x64 安装包、应用源码、Librempeg 对应源码及 `SHA256SUMS.txt`。
